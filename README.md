## Project Overview
A fully responsive, interactive website for "Kota Kings & Burger Queens", a local fast-food business based in Polokwane. The site features a dynamic menu, a functional contact form, and is optimized for search engines.

## Changelog (Updates from Part 2 to Part 3)
*The following changes were made based on feedback and new requirements for Part 3:*

- **JavaScript Enhancements (Interactive Elements):** 
  - Implemented an interactive Lightbox gallery on the Home and About pages using JavaScript, allowing users to view images in a larger format without leaving the page.
  - Added a live search/filter functionality on the Menu page using DOM manipulation to help users find items quickly.

- **JavaScript Form Validation & AJAX:**
  - Added client-side JavaScript validation to the Contact Us form to check for valid names, email formats, and ensure the message field is not empty.
  - Implemented a simulated AJAX submission that displays error messages or a successful submission message without reloading the page.

- **Search Engine Optimization (SEO):**
  - **On-Page SEO:** Added unique Meta Descriptions and Keywords to the `<head>` of all HTML pages. Fixed accessibility by ensuring only one `<h1>` heading exists per page.
  - **Image Optimization:** Replaced generic image `alt` tags (e.g., "image") with descriptive text for better indexing.
  - **Technical SEO:** Created a `robots.txt` file to instruct search engine crawlers, and a `sitemap.xml` file to help search engines understand the website structure.
  - **Off-Page SEO:** Ensured social media links (Facebook, Instagram, Twitter) in the footer use `target="_blank"` and `rel="noopener"` attributes to encourage brand sharing. Added a Google Maps embed for Local SEO.
